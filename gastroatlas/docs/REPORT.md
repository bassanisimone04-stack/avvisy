# Stato della migrazione

**Fatto:** homepage (terrazza → città → esperienze → Toscana, poi il resto), elenco ristoranti con filtri/ordinamento/ricerca, rotta per città,
schede con galleria, preferiti, confronto con link condivisibile, ricerca con `/`, cambio lingua, e le altre pagine del menu (destinazioni, esperienze,
hotel, viaggio in Toscana, magazine, indice prezzi, metodologia, informazioni legali, chi siamo, concierge, club/regali/account/business come "non configurato").

**Non fatto:** database e ruoli (Supabase), mappe, pagamenti, prenotazioni, newsletter, AI, back office, dati reali.
Il catalogo è fittizio e il sito è escluso dall'indicizzazione.

**Differenze volute rispetto all'originale:** font DM Sans incluso nel sito (niente Google Fonts), foto ottimizzate (AVIF/WebP, dimensioni diverse per schermo),
badge "Demo" su ogni scheda, frecce nella galleria, link di cambio lingua con nome accessibile completo.
