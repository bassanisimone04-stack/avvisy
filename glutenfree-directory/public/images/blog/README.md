- **Orizzontale, con il soggetto al centro**: nella pagina dell'articolo la foto viene ritagliata quadrata, nelle anteprime in formato 16:9.

- **Solo foto tue**, mai prese da internet (diritti d'autore).
- **Niente persone riconoscibili** senza il loro consenso, soprattutto bambini.
- Se la foto è scattata in un locale reale, chiedi il permesso al titolare e scattala **davvero lì**: non usare una foto qualsiasi per un locale specifico.
