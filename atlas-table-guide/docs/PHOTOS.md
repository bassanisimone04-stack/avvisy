# Foto da inserire

Oggi tutte le immagini sono **illustrazioni generate** (non foto). Per usare foto vere:

1. Metti i file in una cartella con questi nomi (estensione libera: jpg, png, webp).
2. Facoltativo: `credits.json` con licenza, autore e fonte di ogni foto.
3. Esegui `npm run photos -- ./cartella` e poi `npm run build`.

Lo script ritaglia ogni foto al formato giusto, crea l'anteprima sfocata e toglie l'etichetta "Immagine illustrativa". **Usa solo foto che hai il diritto di pubblicare** (tue, con licenza, o fornite dai ristoranti). Non usare foto prese da altri siti.
